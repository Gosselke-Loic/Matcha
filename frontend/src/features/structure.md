Folder features enclosing all necessary logic for features/view on the website.

1. Folder api:
  - Contain the mutations (Tanstack Query).
2. Folder components:
  - Contain the components (ex. forms, modal, etc...) for that especific feature.
3. Folder store:
  - Use zustand for contexts, keep state of the for that feature.
4. Folder schemas:
  - Schemas with zod, shapes for the data used in this feature.
